# 골드레슬링 회원 관리·예약 시스템 — 기능 요구사항 (requirements.md)

> 이 문서는 확정 스펙의 단일 진실 공급원(SSOT)이다.
> 도메인 규칙의 상세는 `policies.md`, 용어·네이밍은 `glossary.md`를 따른다.
> 문서 간 충돌 시 policies.md > requirements.md 순으로 우선한다.

## 1. 프로젝트 개요

- 레슬링 체육관 "골드레슬링"의 회원 관리 및 수업 예약 웹 서비스
- MVP 범위: **송파점 단일 지점** 운영 (전국 6개 지점 중 1개)
- 확장 전제: 추후 지점 간 연동(타 지점 횟수권 예약, 관리자 교차 권한)이 가능하도록
  모든 핵심 엔티티에 `branch_id`를 두고, 관리자 권한은 관리자↔지점 다대다 매핑으로 설계한다.
  단, MVP에서는 매핑이 1:1이며 교차 기능은 구현하지 않는다.

## 2. 사용자 역할

| 역할           | 설명                                               |
| -------------- | -------------------------------------------------- |
| 회원 (MEMBER)  | 카카오 로그인으로 가입, 관리자 승인 후 서비스 이용 |
| 관리자 (ADMIN) | 지점 담당자. 회원·이용권·예약·출석·공지 관리       |

## 3. 회원 기능

### 3.1 가입/로그인

- 카카오 OAuth 로그인으로 가입
- 가입 직후 상태는 `승인대기(PENDING)`. 로그인은 가능하나 "승인 대기 중" 화면만 노출
- 관리자 승인 후 `활성(ACTIVE)` 전환, 전체 기능 사용 가능

### 3.2 이용권 조회

- 본인이 보유한 이용권 목록·잔여 횟수·유효기간·만료일 조회
- 차감/복구 이력 조회 (언제, 무슨 사유로 몇 회가 오갔는지)
- 한 회원이 여러 이용권을 동시 보유 가능 (예: 저녁반 회비 + 1:1 레슨권)

### 3.3 예약

- 주간 시간표에서 예약제 수업(SESSION) 예약 — 예약제 횟수권(SESSION_PASS) 필요
- 1:1 레슨(LESSON) 예약 — 레슨권(LESSON_PASS) 필요, 타임당 1명만
- 예약 규칙(오픈 시점, 정원, 당일 취소 불가, 즉시 차감 등)은 policies.md §3 참조
- 본인 예약 목록 조회 / 변경 / 취소

### 3.4 공지사항

- 관리자가 등록한 공지 목록·상세 열람 (공휴일 시간표, 이벤트 등)

## 4. 관리자 기능

### 4.1 회원 관리

- 가입 승인 / 거절
- 회원 목록·상세 조회, 상태 변경 (`활성 / 휴회 / 비활성`)
- 회원 검색

### 4.2 이용권 관리

- 회원에게 이용권 등록 (오프라인 결제 후 수기 등록 — 시작일 지정 가능, D-055)
  - 저녁반 회비: 1 / 3 / 6개월
  - 예약제 횟수권, 1:1 레슨권: 횟수 지정 (0.5 단위 자유 입력)
- 횟수 수동 가감 (사유 입력 필수 → 이력에 남음. 정책은 policies §4.2a)
- 저녁반 기간 수정/연장 (이벤트, 휴회 보상, 추가 결제 대응)
- 횟수권(`SESSION_PASS`/`LESSON_PASS`) 유효기간 수정 (만료 후 서비스 부여 대응 — D-056)
- 이용권 등록 취소 (오등록 정정 — 취소 상태 전환 + 이력, 물리 삭제 없음 — D-059)

### 4.3 예약 관리

- 모든 회원의 예약 조회
- 회원 예약 대리 취소 / 일시·타임 변경 (당일 포함 — 관리자는 제약 없음)
- 관리자 취소 시 차감 복구 여부 선택 (기본: 복구)

### 4.4 수업 운영

- 특정 날짜의 특정 수업 **휴강 처리** → 해당 예약 자동 취소 + 차감 복구
- 모든 수업(저녁반/예약제/1:1)에 대한 **출석 체크(명단 관리)** — policies.md §6
- 횟수권 회원의 저녁반 참여 시 0.5회 수동 차감

### 4.5 관리자 대시보드

- **주간 스케줄 보드**: 요일 × 타임슬롯 그리드. 셀에 수업 종류·예약 인원(n/정원)·1:1 여부 표시.
  셀 클릭 → 예약자 명단 + 출석체크 + 취소/변경을 한 패널에서 처리.
  모바일에서는 일 단위 리스트 뷰로 전환
- **알림센터**: 예약 생성/변경/취소 발생 시 알림 생성, 미확인 뱃지.
  MVP는 폴링(30초), 이후 SSE로 업그레이드
- **최근 활동 피드**: 예약 이벤트 타임라인 (알림과 동일 데이터의 다른 뷰)

### 4.6 공지사항 관리

- 공지 등록 / 수정 / 삭제

## 5. 비기능 요구사항

- **반응형**: 회원·관리자 화면 모두 데스크탑/모바일 대응
- **알림(푸시)**: MVP 제외. v2 후보 = PWA + FCM 웹 푸시 (무료)
- **인프라**: 무료 지향 — AWS EC2(BE+DB, Docker) + S3/CloudFront(FE) + GitHub Actions
- **정합성**: 동시 예약(정원 마지막 자리, 1:1 슬롯)에서 초과 예약 0건 보장 — DB 제약 + 락
- **감사 가능성**: 모든 차감/복구는 이력 테이블에 기록
- **API 계약**: 백엔드 springdoc이 생성하는 `docs/api/openapi.yaml`이 FE·BE 간 유일한 진실

## 6. MVP 제외 (v2 이후 후보)

- 지점 간 연동 (교차 예약, 교차 관리자 권한)
- 온라인 결제(PG)
- 웹 푸시 알림 (PWA + FCM)
- 정원 초과 대기(waitlist)
- 카카오 알림톡
