<objective>

**"잔여 = 이력 합계" 불변식을 실제 DB에서 증명**한다.

Purpose: 이 프로젝트의 Core Value("회원이 보는 잔여 횟수는 항상 실제 사용 가능 횟수와 일치한다")가

같은 트랜잭션 이력 저장" 3단 구조를 Phase 4의 예약 차감이 그대로 재사용한다.
