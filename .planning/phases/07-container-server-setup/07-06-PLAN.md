   기대: **exit 0**, Docker 설치·스왑 생성 블록이 스킵되고, 스크립트 끝의 상태 요약 출력이 1회차와 같다.
4. **결과 비교** — 두 로그의 상태 요약 부분(`docker --version`, `docker compose version`, `swapon --show`, 타임존, `ls -la /opt/gold-wrestling`)을 비교한다. `diff <(tail -20 /tmp/setup-run1.log) <(tail -20 /tmp/setup-run2.log)` 가 비어 있으면 멱등이다.
5. **부작용 확인** — `swapon --show`에 `/swapfile`이 **1개만** 있고, `grep -c swapfile /etc/fstab`이 `1`이어야 한다(중복 추가 없음). `/opt/gold-wrestling/.env`가 존재하고 소유자가 `ubuntu`여야 한다.
6. **git 부재 확인** — `ls -a /opt/gold-wrestling | grep -c '^\.git$'` 가 `0` (D-18).

실패하면 어느 블록에서 멈췄는지 로그 라인을 그대로 알려주세요 — 스크립트의 가드를 고쳐야 합니다.
