**JwtConfig.kt** — `@Configuration` 클래스, 생성자로 `JwtProperties` 주입.
`javax.crypto.spec.SecretKeySpec`을 `jwtProperties.secret.toByteArray()` + `"HmacSHA256"`으로 만들고,
- `@Bean fun jwtEncoder(): JwtEncoder` = `NimbusJwtEncoder(ImmutableSecret(secretKey))`
- `@Bean fun jwtDecoder(): JwtDecoder` = `NimbusJwtDecoder.withSecretKey(secretKey).macAlgorithm(MacAlgorithm.HS256).build()`
**`macAlgorithm(HS256)`을 반드시 명시한다** — 토큰 헤더의 `alg` 값을 신뢰하지 않게 만드는 알고리즘 confusion
방어다(RESEARCH Security Domain). 그 이유를 KDoc 한 줄로 남긴다.
`ImmutableSecret`의 정확한 패키지 경로는 RESEARCH가 MEDIUM confidence로 표시한 항목이다 —
**verify-boot4-api 절차를 그대로 수행한다**: context7로 Spring Security 7 문서에서
`NimbusJwtEncoder`/`ImmutableSecret` 시그니처 확인 → 필요하면 로컬 Gradle 캐시에서 클래스 위치 검색
(`find ~/.gradle/caches ... unzip -l ... | grep ImmutableSecret`) → `./gradlew compileKotlin`으로 확정.
추측한 임포트로 넘어가지 않는다.
`jwtProperties.secret`가 비어 있거나 32바이트 미만이면 빈 생성 시점에 `IllegalStateException`을 던진다 —
운영에서 시크릿 미주입으로 "서명은 되는데 아무나 위조 가능한" 상태가 되는 것을 기동 실패로 바꾼다.
예외 메시지에 시크릿 값을 절대 포함하지 않는다.

**ClockConfig.kt** — `@Configuration` + `@Bean fun clock(): Clock = Clock.system(ZoneId.of(SEOUL_ZONE_ID))`.
`SEOUL_ZONE_ID`는 `com.goldwrestling.SEOUL_ZONE_ID` 상수를 임포트해 쓴다(문자열을 다시 적지 않는다).
KDoc에 "현재 시각은 이 빈에서만 얻는다 — `OffsetDateTime.now()` 직접 호출 금지 (conventions §5)"를 남긴다.

**KakaoRestClientConfig.kt** — `@Configuration`, 생성자로 `KakaoProperties` 주입.
`@Bean fun kakaoRestClient(builder: RestClient.Builder): RestClient` 를 만든다.
- baseUrl을 설정하지 않는다 — 토큰 교환(`kauth.kakao.com`)과 사용자 조회(`kapi.kakao.com`)가 서로 다른 호스트다
- 연결·읽기 타임아웃을 설정한다. 외부 API가 응답하지 않을 때 우리 요청 스레드가 무한 대기하면
  로그인 전체가 멈춘다. 값은 연결 3초 / 읽기 5초로 한다
- **Boot 4에서 `RestClient.Builder`에 타임아웃을 거는 정확한 API는 추측하지 않는다** —
  verify-boot4-api 절차대로 context7에서 Spring Framework 7 / Boot 4.1의
  `ClientHttpRequestFactoryBuilder` 또는 `ClientHttpRequestFactorySettings` 사용법을 확인한 뒤 적용하고,
  `./gradlew compileKotlin`으로 검증한다
- 이 빈이 목킹 대상이라는 점(`MockRestServiceServer.bindTo(builder)`)을 KDoc에 남긴다
