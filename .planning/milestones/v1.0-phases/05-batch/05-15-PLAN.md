<objective>
WR-05를 닫는다 — 수동 실행 API가 배치 종료까지 Tomcat 스레드를 붙잡는 **동기 호출**이라,
프록시·LB 타임아웃(기본 60s)으로 관리자가 응답을 못 받고 재시도하면 CR-01의 이중 차감이 그대로
재현된다. 05-GAP-CONTEXT §2.4 확정안대로 **셋 다** 한다:
- `POST /api/admin/batch/inactivity-runs` — 시작(`RUNNING` 삽입)은 **동기**로 해서 중복 요청이
  즉시 409를 받게 하고, 본문은 전용 실행기로 넘겨 **202 Accepted** + `batchExecutionId`를 즉시 반환
- `GET /api/admin/batch/inactivity-runs/{id}` — 폴링용 단건 조회
- `GET /api/admin/batch/inactivity-runs` — 최근 실행 목록(D-108의 "배치가 안 돌았는지는 실행
  이력으로 확인한다"를 실제로 가능하게 만든다)

Purpose: 가드(05-11~13)가 있어도 관리자가 타임아웃→재시도 경로를 계속 밟으면 운영이 불편하고
